## Purpose

Presents one invocation surface over the external language-model providers the agent can be configured against.

## Scope

**In scope**

- Provider selection and client construction.
- Timeout, retry and option mapping.
- A uniform failure contract.

**Out of scope**

- Agent behaviour and routing (SPEC-100).
- Embedding providers (SPEC-160).
