## Purpose

Defines what every embedding implementation must satisfy, so that one can be exchanged for another without the rest of the system noticing.

## Scope

**In scope**

- The vectorizer contract common to all implementations.
- Model identity and vector dimension.
- Determinism and versioning requirements.

**Out of scope**

- Any one implementation's internals (SPEC-161 to SPEC-163).
